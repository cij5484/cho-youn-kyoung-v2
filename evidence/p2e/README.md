# P2E visual and validation evidence

This is a development-only Hero→Haegeum prototype, not final source or device quality approval.

- `overview.png`: four desktop stages together; final panel is labelled AI reference.
- `initial-comparison.json`: initial frame pixel comparison against approved P2D, excluding scrollbar.
- `video-metadata.json`: duration and dimensions decoded by the browser.
- `desktop-initial.png`: shared approved B first frame.
- `desktop-hero-exit.png`, `desktop-head.png`, `desktop-bow-entry.png`, `desktop-bow.png`, `desktop-resonance.png`, `desktop-full-entry.png`, `desktop-full.png`: one continuous desktop timeline, including intermediate masks.
- `mobile-390-*.png`, `mobile-320-*.png`: separately authored mobile framing.
- `wide-full.png`, `tablet-bow.png`: wide/tablet composition.
- `reduced-sequence.png`, `mobile-reduced-sequence.png`, `text-200.png`: semantic static and enlarged-text fallback.
- `webkit-head.png`, `webkit-bow.png`, `webkit-resonance.png`, `webkit-full.png`: automated WebKit engine captures; **not relabeled physical Safari screenshots**.
- `desktop-realtime.webm`, `mobile-realtime.webm`: normal-speed browser recordings with native wheel progression and reversal. No paused-animation or slowed footage.
- `asset-provenance.json`: real-photo and AI-reference source/derivative provenance kept distinct.
- `delivery-p2d.json`: exact P2D commit/Fast CI receipt and committed file list.
- `full-gate.txt`, `haegeum-test-results.json`, `local-performance.json`, `verification.json`: final validation and scope evidence.
